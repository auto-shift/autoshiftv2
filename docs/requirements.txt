# Documentation toolchain. Referenced by .github/workflows/ci.yaml (build check) and
# .github/workflows/docs.yaml (publish), so both always run the same generator version.
#
# A manifest rather than an inline `pip install` in each workflow: neither Dependabot nor Renovate
# reads a version out of a `run:` step, so an inline pin is frozen forever. Dependabot picks this
# file up through the pip ecosystem entry in .github/dependabot.yml.
#
# Pinned exactly, not floored: Zensical is before version 1.0 and ships breaking changes between
# patch releases. An unpinned docs toolchain is how ProperDocs silently replaced MkDocs as the
# generator for this site.
